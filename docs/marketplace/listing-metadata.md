## Q&A drafts

**The shortcut does not work.**
Open *Tools > Options > Environment > Keyboard*, find `Tools.PasteIntoAll` and check that it is bound to `Ctrl+Alt+Shift+O`. If the box is empty, press the combination and click *Assign* — or just restart Visual Studio: the extension re‑applies the default binding on startup. A log line in `%TEMP%\paste-into-all.log` confirms it.

**The text is not pasted.**
Raise *Paste delay (ms)* in *Tools > Options > Paste into all*. If OpenCode runs inside a terminal, check *Target application* — it also accepts a fragment of the window title.

**Can I send the code somewhere other than OpenCode?**
Yes — set *Target application* to a process name or a window‑title fragment (`Code`, `chrome`, `notepad`, `vscode`). Autostart then no longer applies: the application has to be running.

**Can I send the path and the code together?**
Yes — enable *Also append the file contents for a whole file*.

**Does it send my code anywhere?**
No. The extension has no network access. It uses the local Windows clipboard to move text from Visual Studio to the target window.

**I set a process name but nothing is pasted.**
The application must already be running with at least one visible window — only OpenCode is started automatically. Also try the process name from Task Manager (`Code`, `chrome`, `notepad`) or a word from the window title (`vscode`, `блокнот`).
