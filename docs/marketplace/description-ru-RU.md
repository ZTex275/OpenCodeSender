# OpenCode Sender

**Отправка кода из Visual Studio прямо в чат OpenCode — одно нажатие вместо ручного копирования.**

Вы разбираете метод в Visual Studio и хотите спросить о нём OpenCode. Обычно это значит: выделить код, `Ctrl+C`, переключиться на другое окно, кликнуть в поле ввода, `Ctrl+V`, вернуться назад. И так каждый раз.

OpenCode Sender заменяет всё это одним нажатием **`Ctrl+Alt+Shift+O`**.

---

## Как это работает

1. Выделите фрагмент кода в редакторе Visual Studio.
2. Нажмите **`Ctrl+Alt+Shift+O`** — или выберите **Средства → Отправить в OpenCode**, или нажмите правой кнопкой в редакторе и выберите **Отправить в OpenCode**.
3. Фрагмент оказывается в поле ввода чата OpenCode — остаётся только задать вопрос.

Окно OpenCode выводится на передний план автоматически. Если приложение ещё не запущено, расширение запустит его, дождётся появления окна и вставит текст.

### Любое целевое приложение

Нужно отправить код не в OpenCode, а в VS Code, браузер или блокнот? Укажите в настройке **Target application** имя процесса (`Code`, `chrome`, `notepad`) или часть заголовка окна — и текст будет вставляться туда. Названия без пробелов тоже понимаются: `vscode` находит окно «Visual Studio Code». Автозапуск работает только для OpenCode.

### Фрагмент или целый файл

Расширение осознанно подходит к тому, **что именно** отправлять:

| Что выделено | Что получает OpenCode |
| --- | --- |
| Фрагмент кода | Сам фрагмент, дословно — без лишнего пути вокруг |
| Весь файл или ничего | Только **полный путь** к файлу, например `D:\Projects\App\Services\UserService.cs` |

Путь вместо тысячи строк кода сохраняет чат компактным и даёт OpenCode возможность открыть файл самостоятельно. Если нужно отправлять и путь, и содержимое — для этого есть настройка.

## Чем это удобно

- **Никакого переключения окон.** Без `Alt+Tab` и поисков поля ввода.
- **Настоящая горячая клавиша, а не поиск по меню.** `Ctrl+Alt+Shift+O` работает в любом месте IDE, включая редактор кода.
- **Умное содержимое.** Фрагмент остаётся фрагментом, файл превращается в путь.
- **Автозапуск.** OpenCode закрыт? Расширение запустит его, дождётся окна и вставит текст.
- **Любой получатель при желании.** По умолчанию текст уходит в OpenCode, но настройкой `Target application` можно направить его в любое приложение — VS Code, браузер, терминал.
- **Аккуратная вставка.** Окно сначала выводится на передний план, и только после проверки, что на переднем плане именно оно, отправляется `Ctrl+V`. В саму Visual Studio текст не попадает никогда.
- **Локализация.** В русской Visual Studio команда называется *Отправить в OpenCode*, в английской — *Send to OpenCode*; страница настроек (названия параметров, подсказки и группы «Вставка»/«Содержимое») и запись в диспетчере расширений тоже переведены.
- **Без сети и телеметрии.** Расширение не обращается к интернету. Оно только переносит текст между двумя приложениями на вашем компьютере.

## Настройки

**Средства → Параметры → OpenCode Sender → General**

| Параметр | По умолчанию | Назначение |
| --- | --- | --- |
| Paste delay (ms) | `350` | Пауза после активации окна OpenCode перед `Ctrl+V`. Увеличьте на медленной машине, если текст иногда не вставляется. |
| Start OpenCode when it is not running | Вкл. | Запускать OpenCode автоматически, если окно не найдено. |
| Startup timeout (seconds) | `30` | Сколько ждать появления окна после запуска. |
| OpenCode executable path | *(пусто)* | Необязательный явный путь к `OpenCode.exe`. Пусто — автопоиск. |
| OpenCode window title filter → **Target application (process or window title)** | `opencode` | Куда вставлять текст: имя процесса (`opencode`, `chrome`, `Code`, `notepad`) или фрагмент заголовка окна. Пусто или `opencode` — OpenCode. |
| Send the full file path when the whole file is selected | Вкл. | Весь файл → только путь. |
| Also append the file contents for a whole file | Выкл. | Отправлять путь, а после него — код. |
| Treat an empty selection as the whole file | Вкл. | Нет выделения → считается, что выбран весь файл. |

Комбинацию можно переназначить в **Средства → Параметры → Окружение → Клавиатура** (команда `Tools.SendtoOpenCode`). Если привязка когда‑либо пропадёт — например, после импорта параметров с другой машины — расширение восстановит `Ctrl+Alt+Shift+O` при запуске.

## Требования

- **Visual Studio 2026** (версия 18.0 или новее), Community, Professional или Enterprise, 64‑битная.
- **.NET Framework 4.7.2** или новее.
- Приложение **OpenCode** для рабочего стола (нужно, если отправляете в OpenCode). Если оно установлено в нестандартную папку, укажите путь в настройках.
- Раскладка клавиатуры, на которой можно набрать `O`: комбинация привязана к физической клавише `O`, поэтому работает и при русской раскладке.

---

## Конфиденциальность

У OpenCode Sender нет доступа к сети, аналитики, телеметрии и фоновых служб. Единственные данные, с которыми он работает, — текст, который вы сами отправляете; он передаётся из редактора Visual Studio в окно OpenCode через стандартный буфер обмена Windows. Диагностика пишется локально в `%TEMP%\opencode-sender.log` и никогда не покидает ваш компьютер.
